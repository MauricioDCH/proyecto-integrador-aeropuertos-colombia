# Entregables del proyecto

Esta carpeta contiene enlaces y accesos rápidos a los principales entregables digitales del proyecto integrador.

## Contenido

| Archivo                   | Descripción                                                             |
| ------------------------- | ----------------------------------------------------------------------- |
| `enlace_dashboard.txt`    | Contiene el enlace al dashboard interactivo desarrollado en Streamlit.  |
| `enlace_presentacion.txt` | Contiene el enlace a la presentación interactiva desarrollada en React. |

## Dashboard interactivo

El dashboard permite explorar visualmente el comportamiento operacional y meteorológico de los aeropuertos colombianos incluidos en el proyecto.

Incluye vistas de:

* Operaciones aeroportuarias.
* Pasajeros movilizados.
* Carga transportada.
* Conectividad.
* Condiciones meteorológicas METAR.

## Presentación interactiva

La presentación React fue desarrollada como material de apoyo para la exposición final del proyecto.

Incluye:

* Contexto del problema.
* Fuentes de datos.
* Proceso de preparación.
* Análisis exploratorio.
* Ingeniería de características.
* Desarrollo de modelos.
* Resultados.
* Conclusiones.
* Referencias.

## Nota

Los enlaces incluidos en esta carpeta corresponden a los productos finales desplegados o preparados para la entrega del proyecto.
